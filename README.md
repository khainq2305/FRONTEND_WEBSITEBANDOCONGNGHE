# Website Kinh Doanh Thiết Bị Điện Gia Dụng

## Giới thiệu
Website thương mại điện tử bán thiết bị điện gia dụng, tối ưu trải nghiệm trên desktop và mobile.  
Tích hợp **AI gợi ý sản phẩm**, **chatbox hỗ trợ khách hàng theo thời gian thực**, và **flash sale** giúp tăng trải nghiệm cá nhân hóa và tỷ lệ chuyển đổi.  

## Công nghệ sử dụng
- Frontend: React, TailwindCSS, TypeScript  
- Backend: Node.js, Express  
- AI Recommendation: Python  
- Database: MYSQL  
- Thanh toán: COD, VNPay, MoMo, VietQR, Zalo, Visa  

## Tính năng chính
- Chatbox tư vấn khách hàng theo thời gian thực  
- AI gợi ý sản phẩm dựa trên hành vi và lịch sử tìm kiếm  
- Tích hợp flash sale, khuyến mãi  
- Thanh toán online COD, VNPay, MoMo, VietQR, Zalo, Visa , Cod 
- Quản lý sản phẩm, đơn hàng, người dùng
